# AIに改修を依頼するときのプロンプト

ChatGPT / Claude / Gemini などに改修を依頼する際は、以下をコピーして使ってください。
必ず次のファイルを一緒に渡してください。

- `CLAUDE.md` … 編集時の制約・確認チェックリスト(ルールの本文はここにだけ書いてある)
- `docs/SPEC.md` … 設定スキーマ・voiceId形式・外部連携などの仕様
- 改修対象のファイル(通常は `index.html`、Premiere操作なら `jsx/host.jsx`、
  A.I.VOICE2関連なら `bridge/aivoice2_bridge.ps1`)

Claude Code でこのリポジトリを開いて作業する場合は、`CLAUDE.md` が自動で読み込まれるため本書は不要です。

---

```
あなたはAdobe CEPエクステンションの開発者です。
Premiere Pro用パネル「VoiceDesk」を改修してください。

## 前提
- 添付の CLAUDE.md の「重要な制約」はすべて厳守してください。
- 仕様(設定スキーマ、voiceId形式、外部連携、保存・配置・字幕の挙動)は添付の docs/SPEC.md に従い、
  既存の設定ファイル・台本データとの互換性を壊さないでください。

## 改修内容
(ここに依頼内容を書く)

## 出力形式
- 変更したファイルの全文、または適用箇所が一意に特定できる差分
- 変更点の要約と、動作確認手順
- 仕様が変わる場合は docs/SPEC.md の更新案
```

---

改修後は `CLAUDE.md` の「変更後の手動確認チェックリスト」で確認してください。
